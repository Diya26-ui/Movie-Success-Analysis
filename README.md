# 🎬 Movie Success Analysis

A data analysis project exploring IMDb movie data using Python, Pandas, Matplotlib, and Seaborn to uncover insights about movie ratings, genres, budgets, and revenue trends through visualizations and Exploratory Data Analysis (EDA)

## 📌 Project Objective

The goal of this project is to analyze IMDb movie data and identify factors that contribute to movie success using data visualization and exploratory data analysis techniques.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
## 📂 Dataset

Dataset used: IMDb 5000 Movies Dataset from Kaggle.

## 📊 Visualizations Included

- Top 10 Highest Rated Movies
- Distribution of Movie Ratings
- Correlation Heatmap
- Budget vs Revenue Scatterplot
- Rating Distribution by Genre
- Movies Released Per Year Trend
- Most Popular Genres Countplot
## 🔍 Key Insights

- Drama and Comedy are among the most common movie genres.
- Higher budget movies generally generate higher revenue.
- Most movie ratings fall between 5 and 7.
- Movie production increased significantly after 2000.
- Some low-budget movies achieved high IMDb ratings.

The analysis helps uncover trends and relationships in movie industry data using Python visualization libraries.
